### [EN] About
My personalized custom setup based on Linux Mint Xfce. Clean, minimal, and aesthetic configuration featuring WhiteSur-Dark theme and custom Neofetch.

### [RU] О проекте
Кастомизированный сетап на базе Linux Mint Xfce. Минималистичный интерфейс с темой WhiteSur-Dark и измененным выводом терминала.

---

### Included / Что входит в сборку:
- **DE / Окружение:** Xfce 4.18
- **Theme / Тема:** WhiteSur-Dark & ReVista
- **Icons / Иконки:** WhiteSur
- **Software / Софт:** Firefox, Steam, Neofetch
- **Removed / Удалено:** LibreOffice

---

### Installation / Установка

Clone the repository and run the installation script:
клонируйте репозиторий и запустите скрипт:

```bash
git clone https://github.com
cd my-mint-rice
chmod +x install.sh
./install.sh
```
